Why two pages. The curated 75 exist because of a rule, not a taste call — the vocabulary an agency deck actually needs, in four groups (the work · the outcome · the people · the medium we work in). That set is vendored offline and governed. This page is for the times the right emoji genuinely isn't in it: find it here, use it by name, and it resolves from the CDN automatically — the injector already falls back that way. If you reach for one repeatedly, that's a signal to add it to the curated set against the four groups, not to browse harder.

Offline deliverables. Only the 75 are in assets/emoji/. Anything else needs network, so a .pptx, Keynote or air-gapped deck must either stick to the vendored set or embed the file itself.

Skin tone. 310 of these accept a tone (marked T); pass tone="medium". The rest ignore it. Art from microsoft/fluentui-emoji (MIT), pinned to commit 62ecdc0d so it can't shift underneath us.
